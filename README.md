# UniPath

UniPath is an iOS application designed to help university students track, understand, and simulate their academic progress.

The project is currently under active development and is being built from scratch using Swift and SwiftUI.

## Goals

- track completed exams and academic credits
- calculate their weighted GPA
- monitor academic progress
- simulate future exam grades
- estimate their graduation score
- visualize GPA trends over time

## Tech Stack

- Swift
- SwiftUI
- Xcode
- Git
